# ChasClip Backend API

Servicio backend para procesamiento y descarga de videos multimedia con yt-dlp y FFmpeg.

## Despliegue en Render (Gratuito)

1. Crea una cuenta en https://render.com
2. Conecta tu repositorio de GitHub `ChasClip`.
3. Selecciona "New Web Service" y elige el Dockerfile ubicado en `server/Dockerfile` (o usa el archivo `server/render.yaml`).
4. Una vez desplegado, copia la URL generada (por ejemplo `https://chasclip-api.onrender.com`).
5. En la aplicacion web (GitHub Pages), pega esa URL en el campo de configuracion del servidor.
